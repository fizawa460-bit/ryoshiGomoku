# 量子五目並べ

1台のスマートフォンを2人で交互に使うローカル対戦と、2台の端末を直接つなぐオンライン対戦に対応した量子風の五目並べです。

## オンライン対戦

1. 2人とも同じGitHub PagesのURLを開き、「オンライン対戦」を選びます。
2. 黒側が「部屋を作る」を押し、表示された6桁の合言葉を白側へ伝えます。
3. 白側が合言葉を入力して参加すると、自動的に対局が始まります。

通信にはPeerJSの無料クラウド仲介を利用し、盤面データは対戦端末間で直接送受信します。黒側を進行役として、着手と観測結果を両端末へ同期します。ページを閉じると部屋は終了します。

対局開始前のルール選択画面で、基本ルールだけで遊ぶか、追加ルール「量子もつれ」を使うか選択できます。量子もつれの初期設定はOFFです。

## ルール

- 15×15の盤で黒が先手です。
- 白番は `白90% → 白70%` の駒を交互に置きます。
- 黒番も `黒90% → 黒70%` の駒を交互に置きます。
- 盤上の駒が縦・横・斜めに5つ連続すると、観測が解禁されます。
- 観測すると、盤上の全駒がそれぞれの確率に従って一時的に白か黒へ確定します。
- 片方だけ五目が成立すればその色の勝ちです。両方同時に成立した場合は、観測したプレイヤーが勝ちます。
- 観測は1手として扱います。勝敗がつかなければ観測をやめ、全駒を未確定に戻し、観測した側の手番を飛ばして相手から対局を続けます。
- 観測中は新しい駒を置けません。

## 量子もつれ

- 黒と白は、それぞれ対局中に1回だけ量子もつれを使えます。
- 自分の手番で「もつれ」を押し、盤上にある未接続の自分の駒を1個選びます。
- 続けて空いている交点を選ぶと、次の駒が置かれ、2駒が線で結ばれます。この配置で手番を消費します。
- もつれた2駒は観測時に同じ0〜100の乱数を共有します。各駒の確率自体は変わりません。
- たとえば白90%と白70%の駒なら、白白70%・白黒20%・黒白0%・黒黒10%です。2駒の順序を逆にすると、白黒と黒白の確率も逆になります。
- 白白だけが出やすいのではありません。たとえば黒90%の駒同士なら、黒黒90%・白白10%で、黒白・白黒にはなりません。別々に観測した場合の黒黒81%より、2つとも黒になる確率が高まります。
- すでにもつれている駒を、別の駒と重ねてもつれさせることはできません。
- 駒を選ぶ前後に「もつれ取消」を押すと、使用回数を消費せず通常の配置へ戻れます。

## 起動

静的ファイルだけで動作します。`index.html` をブラウザで開くか、任意の静的Webサーバーで配信してください。
